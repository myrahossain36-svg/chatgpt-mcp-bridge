# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Use GitHub's private reporting: the **Security** tab of this repository → **Report a vulnerability**. Include steps to reproduce and the impact. You should get a reply within a few days.

## Scope

In scope: leaking API keys or tokens, authentication bypass in HTTP mode, reading or writing files outside the configured folders, and injection through tool inputs that affects the host.

Out of scope: content generated by OpenAI models, and costs incurred by a bridge deliberately exposed without `MCP_AUTH_TOKEN`.

## Safe deployment checklist

- Keep `OPENAI_API_KEY` in the Claude config, environment or a secrets manager. Never commit it.
- In HTTP mode, always set a long random `MCP_AUTH_TOKEN` and serve over HTTPS.
- Prefer the `Authorization` header over `?token=` where the client allows it.
- Set an OpenAI spending limit and, if useful, `ALLOWED_MODELS`.
- Treat `CONVERSATION_STORE_PATH` and `IMAGE_OUTPUT_DIR` as private data.
